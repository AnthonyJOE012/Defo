# 技能配置

> Defo 项目自动触发技能

## 技能列表

| Skill | 触发条件 | 动作 |
|-------|----------|------|
| frontend-patterns | 打开 `frontend/**/*.tsx` | 提供 React 最佳实践 |
| python-patterns | 打开 `crawlers/**/*.py` | 提供 Python 最佳实践 |
| tdd-workflow | 编写新功能/修复 bug | 强制 TDD 开发流程 |
| supabase-patterns | 涉及数据库操作 | 提供 Supabase 最佳实践 |

## 前端技能

- **framework**: React 18
- **state**: Zustand + TanStack Query
- **storage**: Dexie.js
- **styling**: Tailwind CSS

## 爬虫技能

- **http**: httpx (async)
- **parsing**: beautifulsoup4
- **academic**: scholarly
